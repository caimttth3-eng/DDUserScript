# 阡陌居板块屏蔽助手

[阡陌居](https://www.1000qm.vip/) 论坛油猴脚本：在所有版块列表页按**分类**或**作者**屏蔽帖子，本地持久化。

## 功能

- **按分类屏蔽**：勾选不想看的分类（如历史架空、女频），对应帖子立即从列表隐藏。
- **按作者拉黑**：
  - 点击面板中「当前页作者」chip 一键拉黑；
  - 或直接点帖子列表里作者名旁边的 🚫 小按钮。
- **全局生效**：屏蔽设置跨版块共享——拉黑的作者在任何版块都不显示；屏蔽的分类名在所有版块同样生效。
- **自动适配**：每个版块有自己的分类体系，面板自动列出当前版块的分类供勾选。
- **临时显示**：底部开关可临时显示被屏蔽的内容，方便翻找。
- **非列表页静默**：主页、帖子详情页、个人中心等页面不注入任何 UI。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 打开 `qianmo-blocker.user.js`，点右上角 Raw，Tampermonkey 会提示安装。
3. 或新建脚本，把 `qianmo-blocker.user.js` 内容粘贴进去保存。
4. 打开阡陌居任意版块列表页，右下角出现 🚫 按钮即生效。

## 使用

- 点右下角 🚫 打开面板
- 勾选分类 → 该分类帖子立即隐藏
- 点作者名 → 拉黑该用户
- 已屏蔽用户列表中点 ✕ 解除

## 说明

- 数据存储在浏览器本地（`GM_setValue`，无 Tampermonkey 时回退 `localStorage`），不上传任何服务器。
- 仅在 `#threadlisttableid` 存在的版块列表页激活，不影响其他页面。
